# نظام الموارد البشرية - شركة السلمان (Windows Desktop)

نسخة Electron مستقلة تستخدم **الواجهة العربية RTL الأصلية** ولا تغيّر نسخة PHP/MySQL الموجودة في جذر المستودع. يشغّل التطبيق API محلياً على `127.0.0.1` ويعمل دون PHP أو MySQL أو cPanel أو متصفح أو اتصال بالإنترنت.

## البيانات المحلية

توجد البيانات خارج مجلد تثبيت التطبيق في مجلد Electron `userData/data` لمستخدم Windows (`%APPDATA%/alsalman-hr-desktop/data` عادةً):

- `store.json`: جميع بيانات النظام.
- `kv/`: الصور والمرفقات.
- `backups/`: نسخ تلقائية ذرية، وآخر 60 نسخة محفوظة.
- `outbox/`: رسائل البريد التي تم إنشاؤها في وضع عدم الاتصال.

فصل البيانات عن ملفات التطبيق يعني أنها لا تُحذف عند تثبيت تحديث. يمنع التطبيق تشغيل نسختين في الوقت نفسه لتجنب تعارض الكتابة. تتضمن شاشة الأرشيف تصدير نسخة احتياطية كاملة واستعادتها، بما في ذلك المرفقات، وتُنشأ نسخة أمان تلقائياً قبل كل استعادة.

## التطوير والاختبار

```bash
npm install
npm run check
npm test
npm start
```

الحساب الأولي عند أول تشغيل هو `1005807605` وكلمة المرور `12345`.

## إنشاء Windows 10/11 x64

```bash
npm run dist
```

ينشئ `electron-builder` الملفين التاليين باستخدام أيقونة البرنامج:

- `dist/AlSalman-HR-Setup-1.0.0-x64.exe`
- `dist/AlSalman-HR-Portable-1.0.0-x64.exe`

يشغّل أمر البناء `scripts/prepare-assets.js` أولاً لفك ترميز أيقونة البرنامج الخارجية المرفقة والمحفوظة نصياً داخل `assets/`، ثم إنشاء صور التطبيق و`build/icon.ico` مؤقتاً منها. هذه الملفات الثنائية المولدة مستثناة من Git ولا تدخل في تغييرات Pull Request. المثبت NSIS يسمح باختيار مسار التثبيت وينشئ اختصاري سطح المكتب وقائمة ابدأ. كما يبني workflow الموجود في `.github/workflows/build-windows-desktop.yml` الملفين على Windows ويرفعهما في artifact باسم `AlSalman-HR-Windows-x64`.

## التنظيم

- `src/public/`: الواجهة والأصول الحالية.
- `src/main.js`: نافذة Electron ودورة حياة التطبيق ومنع تعدد النسخ.
- `src/local-server.js`: API والتخزين المحلي والنسخ الاحتياطي والاستعادة.
- `src/preload.js`: جسر Electron محدود وآمن.
- `test/`: اختبارات التكامل والاستمرارية والصلاحيات والنسخ الاحتياطي.
